Alynx's opencode configurations.
================================

Use Ctrl+Enter to submit input, Enter itself is easy to trigger submit while still typing.

Local llama.cpp is assumed to be running on `http://${OPENCODE_LLAMA_HOST}:${OPENCODE_LLAMA_PORT}/` with model `orcarouter-qwen3.8-27b`, so you need to define those environment variables.

A general chat agent is included.
